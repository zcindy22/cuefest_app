This PR introduces the initial implementation of the **Cue** React Native (Expo) festival companion app, capturing all work since the README was published on GitHub. It establishes the full project structure including Expo configuration, navigation layout, all tab screens (Getting There, Stage Finder, My Lineup, Wear & Bring), a local SQLite database layer with seeded sample data, a shared theme system, reusable utility components, and all supporting assets.

It also includes a **polish pass** on the tab bar and Getting There screen:

## Core changes (initial app build)

**`app.json`** — Expo app config: metadata, adaptive Android icons, splash screen, plugins (`expo-router`, `expo-splash-screen`, `expo-sqlite`).

**`app/_layout.jsx`** — Root layout. Loads Bebas Neue, Space Mono, and Inter fonts; initialises SQLite; holds splash screen until ready; renders a `Stack` navigator.

**`app/(tabs)/_layout.jsx`** — Tab navigator with black bar, yellow active tint, and four tabs: Getting There, Stage Finder, My Lineup, Wear & Bring.

**`app/(tabs)/index.jsx`** — Getting There screen. Festival day timeline, simulated transit badge, Google Maps deep-links, 3-step scripted replan flow with history, and a demo reset. State persisted to SQLite.

**`app/(tabs)/stage-finder.jsx`** — Stage Finder screen. Interactive SVG festival map with 13 tappable stage pins, set schedule cards, simulated walk-time, dashed route overlay, and add-to-plan with overlap detection.

**`app/(tabs)/my-lineup.jsx`** — My Lineup screen. Displays sets the user has added to their plan from Stage Finder.

**`app/(tabs)/wear-bring.jsx`** — Wear & Bring screen. Reads a simulated weather forecast from SQLite and displays it with packing tips.

**`db/database.js`** — SQLite singleton. Creates and seeds all tables: `stages`, `sets`, `plan_items`, `replan_log`, `forecast`, `packing_items`, `tips`, `replan_state`.

**`theme/theme.js`** — Centralised palette, font names, and shared style objects (cards, buttons, headings) with neo-brutalist offset shadows.

**`components/DemoLocationChip.jsx`** — Tappable chip to toggle the demo location on/off; reads/writes the `settings` table.

**`lib/location.js`** — Helpers for reading and writing the `demo_location` setting.

**`assets/`** — Festival map SVG/PNG, map data JSON, sample lineup CSV, SpaceMono font, app icons, and splash images.

**`metro.config.js`** — Metro bundler config with SVG transformer support.

**`package.json` / `package-lock.json`** — Expo SDK ~58, `expo-router`, `expo-sqlite`, `react-native-svg`, `@expo/vector-icons`, Google Fonts packages, and dev tooling.

## Polish pass

- **Tab icons** — replaced emojis with Ionicons: outline when inactive, filled when active (`navigate`, `map`, `musical-notes`, `bag-handle`). Inactive: light gray. Active: theme yellow.
- **Tab labels** — Space Mono, 10 px, uppercase.
- **Header bar removed** — `headerShown: false` on all tabs; the Bebas Neue heading on each screen replaces it.
- **Getting There — chip + badge row** — DemoLocationChip and transit badge now share one `flex-wrap` row.
- **Getting There — timeline tightened** — subtitles hidden, dots smaller (18→14 px), connector `minHeight` 20→15, centered, row spacing reduced.
- **Getting There — merged origin card** — "Starting from" input and Open Directions pill button combined into one card.
- **Getting There — collapsible sections** — "Directions home or next stop" and "Replan history" both collapse with a caret; closed by default.
- **Getting There — compact replan row** — Replan button (`flex: 1`) and a small `n/3 used` counter badge side by side.
- **Getting There — empty message** — shortened to "No sets yet. Add one in Stage Finder."
